# my-first-project
鸚鵡飼育具高度專業性，新手飼主常面臨品種辨識困難、不解啃咬天性、用品採購預算難估，以及缺乏數位化健康登記管道等痛點。因此我製作了此系統，希望能降低飼育門檻，並透過數位化工具協助新/舊飼主養育鳥寶們。
